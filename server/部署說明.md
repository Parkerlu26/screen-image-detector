# 帳號伺服器部署說明（Cloudflare Workers + D1）

這個資料夾是「六月幫你顧」的雲端帳號伺服器。部署完成後，同一組帳號密碼就能在任何電腦登入，
你也可以在程式裡的管理後台審核帳號、決定開通多久、產生與追蹤開通碼。

Cloudflare 免費方案就夠用（每天 10 萬次請求、D1 免費額度），不需要信用卡。

## 一、事前準備

1. 註冊一個 Cloudflare 帳號：<https://dash.cloudflare.com/sign-up>
2. 打開命令提示字元，切到這個資料夾：
   ```
   cd C:\Users\nicwe\antigravity\視窗螢幕圖像偵測與提醒器\server
   npm install
   npx wrangler login
   ```
   `wrangler login` 會開瀏覽器要你按同意，按完就回到命令提示字元。

## 二、建立資料庫

```
npx wrangler d1 create june-watcher-auth
```

指令最後會印出一段設定，裡面有 `database_id = "xxxxxxxx-..."`。
把那一串 id 複製起來，貼進 `wrangler.toml` 裡取代 `PUT_YOUR_D1_DATABASE_ID_HERE`。

（`wrangler.toml` 因為含有你自己的 `database_id`，不進版控。如果你是重新 clone 這個專案，
請先把 `wrangler.toml.example` 複製成 `wrangler.toml` 再改。）

**只改 `database_id` 這一行就好**，不要整段覆蓋過去。指令印出的範例會把 `binding` 寫成資料庫名稱
（`june_watcher_auth`），但程式裡是用 `env.DB` 取用資料庫，`binding` 必須保持 `"DB"`，
否則部署會成功、`/api/health` 也正常，但一登入就出現「伺服器發生錯誤」。

接著建表（`schema.sql` 會先清空再建立，所以舊帳號一律重新註冊）：

```
npx wrangler d1 execute june-watcher-auth --remote --file=./schema.sql
```

## 三、設定兩把鑰匙

```
npx wrangler secret put ADMIN_MASTER_KEY
npx wrangler secret put BOOTSTRAP_TOKEN
```

- `ADMIN_MASTER_KEY`：管理員登入時要多輸入的安全金鑰。請自己想一組長一點的隨機字串。
  它只存在 Cloudflare，程式檔案裡完全沒有，反編譯也拿不到。
- `BOOTSTRAP_TOKEN`：只用來開第一個管理員帳號，用完就刪掉（見第五步）。

## 四、上線

```
npx wrangler deploy
```

成功後會印出網址，例如 `https://june-watcher-auth.你的帳號.workers.dev`。
把它記下來，用瀏覽器打開應該會看到 `六月幫你顧 帳號伺服器`。

第一次部署時 wrangler 會問你要不要註冊 workers.dev 子網域，取好之後網址是
`https://<Worker名稱>.<你取的子網域>.workers.dev`（子網域若也取跟 Worker 同名，網址就會出現兩次同樣的字，
那是正常的）。實際網址請看 `wrangler deploy` 印出來的那一行，或是 exe 旁邊 `api-server.txt` 裡填的那一行。

打開 `網址/api/health` 應該看到 `{"success":true,...}`。這一頁沒碰資料庫，所以只代表 Worker 活著；
資料庫綁定對不對要等下一步建好管理員才算驗證完成。

## 五、開第一個管理員帳號

把下面的網址、token、帳密換成你自己的，在命令提示字元執行（PowerShell 請用 `curl.exe`）：

```
curl.exe -X POST https://june-watcher-auth.你的帳號.workers.dev/api/bootstrap ^
  -H "Content-Type: application/json" ^
  -H "X-Bootstrap-Token: 你設定的BOOTSTRAP_TOKEN" ^
  -d "{\"username\":\"你的管理員帳號\",\"password\":\"你的密碼\",\"displayName\":\"管理員\"}"
```

看到 `"success":true` 就成功了。系統只允許在「還沒有任何管理員」時呼叫這個入口，
之後再呼叫都會被拒絕。確認完請立刻刪掉這把 token：

```
npx wrangler secret delete BOOTSTRAP_TOKEN
```

## 六、告訴程式伺服器在哪

在 `六月幫你顧_免安裝綠色版_vX.Y.Z.exe` 所在的資料夾，新增一個檔案 `api-server.txt`，
內容就一行：

```
https://june-watcher-auth.你的帳號.workers.dev
```

存檔後重新開啟程式即可登入。要換伺服器時只改這個檔案，不必重新打包。
（如果想把網址直接寫進程式裡，就在專案根目錄的 `.env` 加上
`VITE_API_BASE="https://..."` 再重新打包，兩種方式都支援，`api-server.txt` 優先。）

## 七、日常使用

- 客戶自己在程式裡「註冊帳號」→ 你在管理後台選好天數按「開通」。
- 或者你先在「開通碼紀錄」頁產生開通碼給他，他在註冊時填、或用「輸入開通碼」頁自助開通與續期。
- 停用帳號後，該帳號在其他電腦上最慢 10 分鐘內（切換視窗回程式時立刻）會被登出。
- 網路斷線時程式仍可離線使用 7 天（`wrangler.toml` 的 `GRACE_DAYS`），超過就必須連網重新登入。

## 常用維護指令

```
npx wrangler tail                                          # 看即時 log
npx wrangler d1 execute june-watcher-auth --remote --command "SELECT username, status, expires_at FROM users"
npx wrangler d1 execute june-watcher-auth --remote --command "SELECT code, status, used_by FROM codes"
```
